# Prototype Judging Rubrics

Total: **100 points** across 6 categories.

| Category | Weight |
| --- | --- |
| Ideation | 25% |
| Impact | 20% |
| Creativity and Novelty | 15% |
| Feasibility | 15% |
| Presentation | 15% |
| Design | 10% |

---

## 1. Ideation — 25%

### Visual Diagram and Mindmaps — 8%

| Score | Description |
| --- | --- |
| 0–1 | No mindmap or diagram present. |
| 2–3 | Single rough sketch or a list dressed up as a diagram. Hard to follow. |
| 4–5 | Clear mindmap showing the core idea and a few branches. |
| 6–7 | Well-structured mindmap with multiple branches and visible connections. |
| 8 | Rich, multi-layered mapping (mindmap + problem tree or user-flow) that clearly illustrates the ideation process. |

### Iteration and Idea Evolution — 7%

| Score | Description |
| --- | --- |
| 0–1 | One idea, unchanged start to finish. |
| 2–3 | Only minor tweaks with it being essentially the first idea. |
| 4–5 | At least one clear pivot or refinement, with reasoning shown. |
| 6–7 | Multiple documented iterations showing how and why the idea evolved, including dropped directions. |

### Mentor Consultation and Feedback Integration — 7%

| Score | Description |
| --- | --- |
| 0–1 | No mentor consulted. |
| 2–3 | Mentor mentioned, but no specific feedback shown. |
| 4–5 | Specific feedback documented and partially acted on. |
| 6–7 | Feedback from mentor(s) is clearly documented and has been meaningfully incorporated into the concept, where appropriate. |

### Breadth of Exploration — 3%

| Score | Description |
| --- | --- |
| 0 | Only one idea ever considered. |
| 1–2 | A couple of alternatives named but not weighed. |
| 3 | Several distinct ideas generated and compared before choosing, with rationale. |

---

## 2. Creativity and Novelty — 15%

### Originality — 7%

| Score | Description |
| --- | --- |
| 0–1 | Copied or very common idea. |
| 2–3 | Similar to existing apps with small changes. |
| 4–5 | Fresh angle on a familiar problem. |
| 6–7 | Demonstrates a genuinely original approach or combines existing ideas in a novel way. |

### Novel Features or Twists — 5%

| Score | Description |
| --- | --- |
| 0–1 | No distinctive features. |
| 2–3 | One smart or unexpected feature. |
| 4–5 | Multiple clever features or a standout twist that defines the product. |

### Differentiation from Existing Solutions — 3%

| Score | Description |
| --- | --- |
| 0 | Indistinguishable from what already exists. |
| 1–2 | Some difference, but overlaps heavily. |
| 3 | Clearly explains why it's different and better than current options. |

---

## 3. Feasibility — 15%

### Technical Viability and Tech Stack — 6%

| Score | Description |
| --- | --- |
| 0–1 | Unrealistic, wrong or no tools. |
| 2–3 | Might work, but major technical gaps. |
| 4–5 | Sound stack, mostly buildable with minor unknowns. |
| 6 | Appropriate technologies are selected, with a realistic implementation approach. |

### Planning and Scope Realism — 5%

| Score | Description |
| --- | --- |
| 0–1 | No plan, scope wildly unrealistic. |
| 2–3 | Rough plan, scope too big or unclear. |
| 4–5 | Clear, achievable scope with a concrete build plan. |

### Resource and Time Awareness — 4%

| Score | Description |
| --- | --- |
| 0–1 | No sense of time, cost, or team limits. |
| 2–3 | Some awareness but gaps remain. |
| 4 | Realistic grasp of what's needed to build it (time, skills, cost). |

---

## 4. Presentation — 15%

### Clarity of Explanation — 5%

| Score | Description |
| --- | --- |
| 0–1 | Confusing; idea not understandable. |
| 2–3 | Understandable but patchy. |
| 4–5 | The idea is explained clearly and is easy to grasp. |

### Structure and Flow — 4%

| Score | Description |
| --- | --- |
| 0–1 | Disorganised, hard to follow. |
| 2–3 | Some structure but jumps around. |
| 4 | Logical, well-paced flow from problem to solution. |

### Delivery and Confidence — 4%

| Score | Description |
| --- | --- |
| 0–1 | Hesitant or flat, hard to engage with. |
| 2–3 | Reasonably confident, some energy. |
| 4 | Confident, engaging, and convincing. |

### Engagement and Persuasiveness — 2%

| Score | Description |
| --- | --- |
| 0 | Doesn't make the idea feel worth building. |
| 1 | Somewhat compelling. |
| 2 | Makes the idea feel genuinely valuable and exciting. |

---

## 5. Design — 10%

### Visual Consistency — 4%

| Score | Description |
| --- | --- |
| 0–1 | No consistency; jarring or missing. |
| 2–3 | Some consistency in colour/type/layout. |
| 4 | Cohesive, polished visual style throughout. |

### Usability and UX — 4%

| Score | Description |
| --- | --- |
| 0–1 | Confusing or unusable. |
| 2–3 | Usable but with friction. |
| 4 | Intuitive, clear UX with attention to how people actually use it. |

### Mockup Completeness — 2%

| Score | Description |
| --- | --- |
| 0 | Missing or fragmentary. |
| 1 | Partial, covers only some key screens. |
| 2 | Covers the core flow end-to-end. |

---

## 6. Impact — 20%

### Understanding the Problem Context — 5%

| Score | Description |
| --- | --- |
| 0–1 | Demonstrates little understanding of the challenge statement. |
| 2–3 | Understands the general problem but misses important aspects or constraints. |
| 4–5 | Clearly demonstrates a strong understanding of the challenge, its causes, stakeholders, and real-world implications. |

### Target Group Alignment — 5%

| Score | Description |
| --- | --- |
| 0–1 | No clear user group. |
| 2–3 | Broad "everyone" audience; weak fit. |
| 4–5 | Specific target users identified, and the solution clearly speaks to their real need. |

### Effectiveness of the Solution — 7%

| Score | Description |
| --- | --- |
| 0–1 | Doesn't really address the problem. |
| 2–3 | Helps a little, but the effect is small or partial. |
| 4–5 | Meaningfully solves the problem for the target group. |
| 6–7 | Solves it significantly and convincingly; clear before/after difference. |

### Reach and Scalability — 3%

| Score | Description |
| --- | --- |
| 0 | One-off, can't grow. |
| 1–2 | Some potential to reach more users. |
| 3 | Clear path to scale or wider impact beyond the initial group. |
